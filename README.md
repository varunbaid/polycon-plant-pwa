# Polycon Plant Forms (home-screen app)

A small wrapper so the plant forms open from an icon on Android and iPhone, full screen, with the Polycon logo.

**Install link:** https://varunbaid.github.io/polycon-plant-pwa/

- **iPhone:** open the link in Safari (not Chrome), tap Share, then **Add to Home Screen**, and name it Polycon Plant.
- **Android:** open the link in Chrome, tap the ⋮ menu, then **Add to Home screen** or **Install app**.

The forms themselves still run at the existing Apps Script address. This page only frames them and supplies the icon and standalone display.
